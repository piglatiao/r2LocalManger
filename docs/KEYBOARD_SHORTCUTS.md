# 键盘快捷键说明

本文档详细说明 R2 存储管理器的所有键盘快捷键。

## 快捷键列表

### 文件操作

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Ctrl+U` | 上传文件 | 打开文件选择对话框，选择要上传的文件 |
| `Ctrl+D` | 下载文件 | 下载当前选中的文件到本地 |
| `Delete` | 删除文件 | 删除当前选中的文件（会有确认提示） |
| `Enter` | 预览文件 | 在预览窗口中打开当前选中的文件 |

### 列表操作

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Ctrl+R` | 刷新列表 | 重新加载存储桶中的对象列表 |
| `↑` / `↓` | 选择文件 | 在对象列表中上下移动选择 |

### URL 复制

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Ctrl+C` | 复制链接 | 复制选中文件的 URL（纯 URL 格式） |
| `Ctrl+Shift+C` | 复制格式菜单 | 显示复制格式选择菜单 |

### 应用程序操作

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `F5` | 刷新列表 | 同 `Ctrl+R`，刷新对象列表 |
| `Esc` | 取消操作 | 关闭对话框或取消当前操作 |

## 使用技巧

### 快速上传文件

1. 按 `Ctrl+U` 打开文件选择对话框
2. 选择文件后按 `Enter` 确认
3. 等待上传完成

### 快速下载文件

1. 使用 `↑` / `↓` 选择要下载的文件
2. 按 `Ctrl+D` 打开保存对话框
3. 选择保存位置后按 `Enter` 确认

### 快速预览文件

1. 使用 `↑` / `↓` 选择要预览的文件
2. 按 `Enter` 打开预览窗口
3. 预览完成后点击关闭或按 `Esc` 关闭窗口

### 快速复制 URL

1. 使用 `↑` / `↓` 选择文件
2. 按 `Ctrl+C` 直接复制 URL
3. 或按 `Ctrl+Shift+C` 选择复制格式

## 注意事项

- 快捷键在主窗口激活时生效
- 预览窗口中的快捷键可能不同
- 某些快捷键在没有选中文件时不会执行操作
- 删除操作始终会有确认提示，防止误操作

## 自定义快捷键

当前版本不支持自定义快捷键。如需此功能，请在 Issue 中提出建议。

# R2 存储管理器 - 发布说明

## 版本 1.0.0

**发布日期**：2024年

### 新功能

#### 核心功能
- ✅ 文件上传 - 支持上传文件到 R2 存储桶，显示上传进度
- ✅ 文件下载 - 支持从 R2 存储桶下载文件到本地，显示下载进度
- ✅ 文件预览 - 支持图片和文本文件的在线预览
- ✅ 文件删除 - 支持删除存储桶中的对象，带确认提示
- ✅ URL 复制 - 支持复制 URL、HTML、Markdown 三种格式

#### 用户界面
- ✅ 简体中文界面 - 所有用户界面文本均为简体中文
- ✅ 工具栏 - 快速访问常用操作
- ✅ 右键菜单 - 便捷的上下文菜单操作
- ✅ 状态栏 - 显示当前状态和对象数量
- ✅ 文件类型图标 - 根据文件类型显示不同图标

#### 用户体验
- ✅ 键盘快捷键 - 完整的快捷键支持
- ✅ 进度显示 - 上传/下载进度实时显示
- ✅ 操作反馈 - 成功/失败消息提示

#### 安装程序
- ✅ Windows 安装程序 - NSIS 安装程序
- ✅ 简体中文安装界面 - 安装向导使用简体中文
- ✅ 自定义安装位置 - 支持选择安装目录

### 技术特性

- **运行时**：Electron
- **S3 SDK**：@aws-sdk/client-s3 v3.x
- **打包工具**：electron-builder
- **国际化**：简体中文（zh-CN）

### 系统要求

- Windows 10 或更高版本
- 网络连接（用于访问 Cloudflare R2）
- Cloudflare R2 API 凭证

### 已知问题

- 大文件预览可能较慢
- 不支持批量操作
- 不支持文件夹上传
- 不支持拖放上传

### 安全说明

- 凭证从环境变量读取，不存储在应用程序中
- 不在日志中记录凭证信息
- 不在 UI 中显示完整凭证

### 升级说明

这是首个正式版本，无需升级。

# 分发包说明

本文档说明 R2 存储管理器的打包和分发流程。

## 构建要求

### 开发环境要求

- Node.js 16.x 或更高版本
- npm 7.x 或更高版本
- Windows 10 或更高版本（用于打包 Windows 版本）

### 依赖安装

```bash
npm install
```

## 构建命令

### 开发模式运行

```bash
npm run dev
```

### 构建应用程序

```bash
npm run build
```

此命令会在 `dist/` 目录创建未打包的应用程序目录。

### 打包 Windows 安装程序

```bash
npm run package:win
```

此命令会创建 Windows 安装程序（.exe 文件）。

## 输出文件

打包完成后，`dist/` 目录包含以下文件：

```
dist/
├── R2 存储管理器 Setup 1.0.0.exe    # 安装程序
├── R2 存储管理器-1.0.0-x64.exe       # 可执行文件（可选）
├── latest.yml                        # 自动更新配置（可选）
└── win-unpacked/                     # 未打包的应用程序目录
    ├── R2 存储管理器.exe
    ├── resources/
    └── ...
```

## 安装程序配置

### NSIS 配置

安装程序使用 NSIS 打包，配置如下：

```json
{
  "nsis": {
    "oneClick": false,
    "allowToChangeInstallationDirectory": true,
    "installerLanguages": ["zh_CN"],
    "language": "2052"
  }
}
```

### 配置说明

| 配置项 | 值 | 说明 |
|--------|-----|------|
| `oneClick` | `false` | 非一键安装，显示安装向导 |
| `allowToChangeInstallationDirectory` | `true` | 允许用户选择安装位置 |
| `installerLanguages` | `["zh_CN"]` | 安装程序语言为简体中文 |
| `language` | `"2052"` | 简体中文语言代码 |

## 版本号规则

使用语义化版本号：`主版本号.次版本号.修订号`

- **主版本号**：不兼容的 API 修改
- **次版本号**：向下兼容的功能性新增
- **修订号**：向下兼容的问题修正

示例：
- `1.0.0` - 首个正式版本
- `1.1.0` - 新增功能
- `1.0.1` - Bug 修复

## 用户安装说明

### 系统要求

- Windows 10 或更高版本
- 网络连接
- Cloudflare R2 API 凭证

### 安装步骤

1. 下载安装程序
2. 双击运行安装程序
3. 按照安装向导完成安装
4. 配置环境变量
5. 启动应用程序

### 配置环境变量

用户需要配置以下环境变量：

```
R2_ACCESS_KEY_ID=your_access_key_id
R2_SECRET_ACCESS_KEY=your_secret_access_key
```

详细配置方法请参考 README.md。

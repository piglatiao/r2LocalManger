# 截图目录

本目录用于存放 R2 存储管理器的使用截图。

## 所需截图列表

以下截图应添加到本目录，用于用户文档：

### 主界面截图

- `main-window.png` - 主窗口界面
- `toolbar.png` - 工具栏特写
- `object-list.png` - 对象列表视图
- `status-bar.png` - 状态栏显示

### 操作截图

- `upload-step1.png` - 点击上传按钮
- `upload-step2.png` - 选择要上传的文件
- `upload-progress.png` - 上传进度显示
- `upload-success.png` - 上传成功提示

- `select-file.png` - 选择要下载的文件
- `save-dialog.png` - 保存对话框
- `download-progress.png` - 下载进度显示
- `download-success.png` - 下载成功提示

- `preview-image.png` - 图片预览窗口
- `preview-text.png` - 文本预览窗口
- `preview-info.png` - 文件信息显示

- `delete-confirm.png` - 删除确认对话框
- `delete-success.png` - 删除成功提示

### 右键菜单截图

- `context-menu.png` - 右键菜单显示

### 安装截图

- `installer-welcome.png` - 安装欢迎页面
- `installer-license.png` - 许可协议页面
- `installer-location.png` - 安装位置选择
- `installer-progress.png` - 安装进度
- `installer-complete.png` - 安装完成页面

## 截图要求

- 格式：PNG
- 分辨率：建议 1920x1080 或更高
- 语言：简体中文界面
- 内容：清晰展示功能，避免敏感信息

## 如何添加截图

1. 在应用程序中执行相应操作
2. 使用截图工具（如 Windows 自带的 `Win+Shift+S`）截取屏幕
3. 保存为 PNG 格式到本目录
4. 更新 `docs/USAGE_GUIDE.md` 中的图片引用

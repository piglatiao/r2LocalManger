## 简介

R2 存储管理器是一款专为 Cloudflare R2 存储服务设计的桌面应用程序，提供直观的图形界面，让您轻松管理存储桶中的文件。

### 主要功能

- 📤 **文件上传** - 支持单个文件和批量上传
- 📥 **文件下载** - 支持单个文件和批量下载
- 👁️ **文件预览** - 支持图片和文本文件在线预览
- 🗑️ **文件删除** - 支持单个文件和批量删除
- 🔍 **搜索筛选** - 按文件名、类型、日期快速查找
- 🖱️ **拖放上传** - 直接拖放文件到窗口即可上传
- ⚙️ **设置管理** - 可视化配置凭证和存储桶

## 系统要求

### 操作系统

- Windows 10 或更高版本

### 网络要求

- 稳定的互联网连接
- 能够访问 Cloudflare R2 API

## 安装与配置

### 安装步骤

1. 下载安装程序（`R2 存储管理器 Setup.exe`）
2. 双击运行安装程序
3. 按照安装向导提示完成安装
4. 安装完成后，桌面会创建快捷方式

### 首次运行配置

应用启动后会先检查当前配置状态：

- 未检测到凭证或必要配置时，只会提示前往“设置”完成配置，不会继续做连接检查。
- 如果本地已保存配置或已设置环境变量，可直接使用。
- 只有检测到已配置但连接失败时，才会提示检查连接或配置。

#### 方式一：通过设置界面配置（推荐）

1. 启动应用程序
2. 点击工具栏的 **"设置"** 按钮
3. 在"凭证配置"标签页中输入：
   - **Access Key ID**：R2 API 访问密钥 ID
   - **Secret Access Key**：R2 API 密钥
4. 点击 **"测试连接"** 验证凭证
5. 点击 **"保存设置"** 保存配置

#### 方式二：通过环境变量配置

创建 `.env` 文件或设置系统环境变量：

```env
R2_ACCESS_KEY_ID=你的AccessKeyID
R2_SECRET_ACCESS_KEY=你的SecretAccessKey
R2_BUCKET_NAME=你的存储桶名称
R2_ENDPOINT=https://xxx.r2.cloudflarestorage.com
R2_PUBLIC_URL=https://pub-xxx.r2.dev
```

### 获取 R2 API 凭证

1. 登录 [Cloudflare Dashboard](https://dash.cloudflare.com/)
2. 进入 **R2 对象存储** 页面
3. 点击 **管理 R2 API 令牌**
4. 创建新的 API 令牌
5. 复制 Access Key ID 和 Secret Access Key

## 基本操作

### 上传文件

#### 方式一：通过按钮上传

1. 点击工具栏的 **"上传"** 按钮（或按 `Ctrl+U`）
2. 在文件选择对话框中，选择要上传的文件
3. 点击 **"打开"** 开始上传
4. 等待上传完成，显示成功提示

#### 方式二：拖放上传

1. 从文件资源管理器中选择文件
2. 直接拖放到应用程序窗口
3. 释放鼠标，自动开始上传
4. 支持同时拖放多个文件

**上传注意事项**：
- 上传会保留原始文件名
- 同名文件会被覆盖
- 大文件上传可能需要较长时间
- 支持同时上传多个文件

### 下载文件

#### 单个文件下载

1. 在对象列表中选择要下载的文件
2. 点击工具栏的 **"下载"** 按钮（或按 `Ctrl+D`）
3. 选择保存位置和文件名
4. 点击 **"保存"** 开始下载

#### 批量下载

1. 按住 `Ctrl` 键点击多个文件进行多选
2. 或按 `Ctrl+A` 全选当前显示的所有文件
3. 点击 **"下载"** 按钮
4. 选择保存文件夹
5. 所有选中的文件将下载到该文件夹

**下载注意事项**：
- 默认使用原始文件名
- 确保有足够的磁盘空间
- 批量下载会显示整体进度

### 预览文件

1. 在对象列表中选择要预览的文件
2. 双击文件或按 `Enter` 键
3. 预览窗口打开，显示文件内容

**支持的预览类型**：

| 类型 | 格式 | 说明 |
|------|------|------|
| 图片 | jpg, png, gif, webp, svg, bmp, ico | 图片查看器，支持缩放 |
| 文本 | txt, md, json, xml, html, css, js, ts, yaml, log | 文本查看器，语法高亮 |
| 其他 | 所有其他格式 | 显示文件元数据信息 |

### 删除文件

#### 单个文件删除

1. 选择要删除的文件
2. 点击 **"删除"** 按钮（或按 `Delete`）
3. 在确认对话框中点击 **"确定"**
4. 文件被永久删除

#### 批量删除

1. 按住 `Ctrl` 键选择多个文件
2. 点击 **"删除"** 按钮
3. 确认删除数量
4. 所有选中的文件将被删除

**⚠️ 重要提示**：
- 删除操作**无法撤销**
- 文件删除后将永久丢失
- 请谨慎操作

### 刷新列表

- 点击 **"刷新"** 按钮（或按 `Ctrl+R`）
- 从 R2 存储桶获取最新的文件列表
- 适用于其他地方有文件变动后同步

## 高级功能

### 搜索文件

1. 在搜索框中输入关键词
2. 列表实时筛选显示匹配的文件
3. 按 `Esc` 或点击 **×** 清除搜索

**搜索特点**：
- 支持模糊匹配
- 不区分大小写
- 搜索文件名中包含关键词的所有文件

### 按类型筛选

1. 点击类型下拉框
2. 选择文件类型：
   - **全部类型** - 显示所有文件
   - **图片** - jpg, png, gif 等
   - **视频** - mp4, avi, mov 等
   - **音频** - mp3, wav, flac 等
   - **文档** - doc, pdf, xls 等
   - **压缩包** - zip, rar, 7z 等
   - **代码** - js, py, java 等
   - **文本** - txt, md, log 等

### 按日期筛选

1. 点击 **"开始日期"** 选择起始日期
2. 点击 **"结束日期"** 选择截止日期
3. 列表显示该日期范围内修改的文件
4. 点击 **"清除日期筛选"** 按钮重置

**日期筛选说明**：
- 包含开始日期当天（从 00:00:00 开始）
- 包含结束日期当天（到 23:59:59 结束）
- 可以只设置开始日期或只设置结束日期

### 组合筛选

搜索、类型筛选、日期筛选可以**组合使用**：

- 例如：搜索 "logo" + 类型 "图片" + 日期范围
- 结果：显示指定日期范围内、文件名包含 "logo" 的图片文件

### 复制文件链接

1. 右键点击文件
2. 选择复制格式：
   - **复制链接** - 纯 URL 格式
   - **复制 HTML** - `<img>` 标签格式
   - **复制 Markdown** - `![]()` 格式
3. 链接已复制到剪贴板

**使用场景**：

```
复制链接：
https://pub-xxx.r2.dev/image.png

复制 HTML：
<img src="https://pub-xxx.r2.dev/image.png" alt="image" />

复制 Markdown：
![image](https://pub-xxx.r2.dev/image.png)
```

### 多选操作

| 操作方式 | 说明 |
|----------|------|
| `Ctrl + 点击` | 添加/移除单个选中项 |
| `Shift + 点击` | 范围选择（从上次点击到当前） |
| `Ctrl + A` | 全选当前显示的所有文件 |
| `Esc` | 取消所有选择 |

## 设置管理

### 打开设置窗口

点击工具栏的 **"设置"** 按钮，打开设置窗口。

### 凭证配置

在 **"凭证配置"** 标签页：

1. **查看状态**：
   - 🟢 凭证已配置 - 可以正常使用
   - 🟠 凭证未配置 - 需要输入凭证

2. **输入凭证**：
   - **Access Key ID**：R2 API 访问密钥 ID
   - **Secret Access Key**：R2 API 密钥（密码形式显示）

3. **显示/隐藏密钥**：
   - 点击 **"显示"** 按钮查看密钥明文
   - 再次点击 **"隐藏"** 隐藏密钥

4. **测试连接**：
   - 点击 **"测试连接"** 验证凭证是否正确
   - 显示连接测试结果

5. **安全设置**：
   - ✅ 加密存储凭证（推荐）
   - 使用系统密钥加密存储凭证

6. **清除凭证**：
   - 点击 **"清除已保存的凭证"**
   - 确认后删除所有保存的凭证

### 存储桶设置

在 **"存储桶设置"** 标签页：

1. **选择存储桶**：
   - 下拉列表显示所有可用的存储桶
   - 点击选择要管理的存储桶

2. **刷新列表**：
   - 点击 **"刷新"** 按钮重新加载存储桶列表

3. **查看端点信息**：
   - 显示当前 R2 端点 URL
   - 显示区域设置（通常为 "auto"）

### 保存设置

1. 完成所有配置后，点击 **"保存设置"**
2. 设置将被加密保存
3. 应用程序将使用新配置重新连接

## 常见问题

### Q: 如何获取 R2 API 凭证？

**A**: 
1. 登录 Cloudflare Dashboard
2. 进入 R2 对象存储页面
3. 点击"管理 R2 API 令牌"
4. 创建新的 API 令牌
5. 复制 Access Key ID 和 Secret Access Key

### Q: 忘记保存的凭证怎么办？

**A**: 
1. 打开设置窗口
2. 清除已保存的凭证
3. 重新输入新的凭证
4. 保存设置

### Q: 上传失败怎么办？

**A**: 
1. 检查网络连接是否正常
2. 确认凭证是否正确（使用测试连接功能）
3. 检查文件名是否包含特殊字符
4. 查看错误提示信息
5. 查看日志文件获取详细错误

### Q: 如何查看日志文件？

**A**: 
日志文件位置：`%APPDATA%/r2-storage-manager/logs/`

或在错误对话框中点击 **"查看日志"** 按钮。

### Q: 支持哪些文件类型预览？

**A**: 
- **图片**：jpg, jpeg, png, gif, webp, svg, bmp, ico
- **文本**：txt, md, json, xml, html, css, js, ts, yaml, yml, log
- **其他**：显示文件信息，不支持内容预览

### Q: 如何批量操作文件？

**A**: 
1. 使用 `Ctrl+点击` 选择多个文件
2. 或使用 `Ctrl+A` 全选
3. 然后执行下载或删除操作

### Q: 删除的文件可以恢复吗？

**A**: 
**不可以**。删除操作是永久性的，文件将无法恢复。请删除前仔细确认。

### Q: 如何切换存储桶？

**A**: 
1. 打开设置窗口
2. 切换到"存储桶设置"标签页
3. 从下拉列表选择其他存储桶
4. 保存设置

### Q: 搜索和筛选可以组合使用吗？

**A**: 
**可以**。搜索、类型筛选、日期筛选可以任意组合，结果为同时满足所有条件的文件。

## 故障排除

### 应用程序无法启动

**可能原因**：
- 缺少运行时依赖
- 配置文件损坏

**解决方案**：
1. 重新安装应用程序
2. 删除配置文件夹：`%APPDATA%/r2-storage-manager/`
3. 重新配置凭证

### 无法连接到 R2

**可能原因**：
- 网络连接问题
- 凭证错误
- 端点配置错误

**解决方案**：
1. 检查网络连接
2. 使用"测试连接"功能验证凭证
3. 确认 R2 服务状态正常
4. 检查防火墙设置

### 上传/下载速度慢

**可能原因**：
- 网络带宽限制
- 文件过大
- R2 服务响应慢

**解决方案**：
1. 检查网络速度
2. 避免在网络高峰期操作大文件
3. 尝试分批上传/下载

### 预览显示乱码

**可能原因**：
- 文本文件编码不是 UTF-8

**解决方案**：
1. 下载文件到本地
2. 使用文本编辑器打开
3. 选择正确的编码方式

### 列表加载失败

**可能原因**：
- 凭证过期
- 存储桶不存在
- 权限不足

**解决方案**：
1. 刷新凭证
2. 确认存储桶名称正确
3. 检查 API 令牌权限

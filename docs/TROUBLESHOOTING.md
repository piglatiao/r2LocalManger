## 启动问题

### 应用程序无法启动

**症状**：双击应用程序后没有反应或立即关闭

**可能原因和解决方法**：

1. **缺少环境变量**
   - 症状：显示"配置错误"对话框
   - 解决：配置 `R2_ACCESS_KEY_ID` 和 `R2_SECRET_ACCESS_KEY` 环境变量
   - 参考：[环境变量配置](#环境变量配置)

2. **缺少依赖文件**
   - 症状：显示"找不到 xxx 模块"错误
   - 解决：重新安装应用程序

3. **权限不足**
   - 症状：显示"拒绝访问"错误
   - 解决：以管理员身份运行应用程序

### 应用程序启动缓慢

**可能原因**：
- 网络连接较慢，初始化 R2 客户端需要时间
- 对象列表较大，加载需要时间

**解决方法**：
- 检查网络连接
- 耐心等待加载完成

## 连接问题

### 网络连接失败

**症状**：显示"网络连接失败，请检查网络设置"

**诊断步骤**：

1. **检查网络连接**
   ```bash
   # 测试网络连接
   ping cloudflare.com
   ```

2. **检查防火墙设置**
   - 确认应用程序被允许通过防火墙
   - Windows 设置 → 更新和安全 → Windows 安全 → 防火墙和网络保护

3. **检查代理设置**
   - 如果使用代理，确认代理配置正确
   - 尝试暂时禁用代理测试

4. **检查 DNS 设置**
   - 尝试使用其他 DNS 服务器（如 8.8.8.8 或 1.1.1.1）

**解决方法**：
- 修复网络连接问题
- 配置防火墙允许应用程序
- 正确配置代理设置

### 连接超时

**症状**：操作长时间无响应，最终显示超时错误

**可能原因**：
- 网络不稳定
- 文件过大
- 服务器响应慢

**解决方法**：
- 检查网络稳定性
- 对于大文件，耐心等待
- 尝试重新操作

## 认证问题

### 认证失败

**症状**：显示"认证失败，请检查 API 凭证配置"

**诊断步骤**：

1. **验证环境变量是否设置**
   - Windows 命令行：
     ```cmd
     echo %R2_ACCESS_KEY_ID%
     echo %R2_SECRET_ACCESS_KEY%
     ```
   - 如果输出为空，说明环境变量未设置

2. **验证凭证格式**
   - Access Key ID 通常为 32 个字符
   - Secret Access Key 通常为 64 个字符

3. **验证凭证有效性**
   - 登录 Cloudflare Dashboard
   - 检查 API Token 是否存在且未过期
   - 确认 Token 权限包含 R2 访问权限

**解决方法**：

1. 重新创建 API Token
   - 登录 Cloudflare Dashboard
   - 进入 R2 → 管理 R2 API 令牌
   - 创建新令牌，选择适当的权限
   - 记录新的 Access Key ID 和 Secret Access Key

2. 更新环境变量
   - 更新 `.env` 文件或系统环境变量
   - 重启应用程序

### 权限不足

**症状**：显示"权限不足，无法执行此操作"

**可能原因**：
- API Token 权限不足
- 存储桶权限配置不正确

**解决方法**：
1. 检查 API Token 权限
   - 确认 Token 有读写目标存储桶的权限
2. 检查存储桶设置
   - 在 Cloudflare Dashboard 中确认存储桶权限

## 文件操作问题

### 上传失败

**症状**：显示"文件上传失败"

**可能原因和解决方法**：

1. **文件被占用**
   - 关闭正在使用该文件的程序
   - 重新尝试上传

2. **文件过大**
   - 当前版本支持大文件上传
   - 检查网络稳定性
   - 耐心等待上传完成

3. **文件名包含特殊字符**
   - 避免使用特殊字符
   - 重命名文件后重试

4. **存储桶已满**
   - 检查 Cloudflare R2 存储配额
   - 清理不需要的文件

### 下载失败

**症状**：显示"文件下载失败"

**可能原因和解决方法**：

1. **磁盘空间不足**
   - 检查目标磁盘空间
   - 清理磁盘或选择其他位置

2. **写入权限不足**
   - 选择有写入权限的保存位置
   - 以管理员身份运行应用程序

3. **文件名冲突**
   - 选择不同的保存位置
   - 重命名文件

4. **对象不存在**
   - 文件可能已被删除
   - 刷新列表后重试

### 删除失败

**症状**：显示"文件删除失败"

**可能原因和解决方法**：

1. **权限不足**
   - 检查 API Token 是否有删除权限

2. **对象不存在**
   - 文件可能已被其他方式删除
   - 刷新列表

## 预览问题

### 图片无法预览

**可能原因**：
- 图片文件损坏
- 网络传输中断
- 不支持的图片格式

**解决方法**：
- 下载文件后使用本地图片查看器打开
- 检查文件是否完整

### 文本文件乱码

**可能原因**：
- 文件编码不是 UTF-8
- 二进制文件被当作文本打开

**解决方法**：
- 下载文件后使用文本编辑器打开
- 选择正确的编码方式

### 预览加载缓慢

**可能原因**：
- 文件过大
- 网络速度慢

**解决方法**：
- 对于大文件，选择下载后查看
- 检查网络连接

### 不支持预览此文件类型

**说明**：某些文件类型不支持在线预览

**解决方法**：
- 下载文件后使用相应的应用程序打开

## 性能问题

### 应用程序运行缓慢

**可能原因和解决方法**：

1. **对象列表过大**
   - 如果存储桶中有大量对象，加载可能较慢
   - 耐心等待加载完成

2. **网络延迟**
   - 检查网络连接质量
   - 尝试使用更稳定的网络

3. **系统资源不足**
   - 关闭其他占用资源的程序
   - 重启应用程序

### 内存占用过高

**可能原因**：
- 预览大文件
- 对象列表过大

**解决方法**：
- 关闭不需要的预览窗口
- 定期刷新列表

## 日志查看

### 日志位置

应用程序日志存储在：
```
%APPDATA%/r2-storage-manager/logs/error.log
```

### 查看日志方法

**方法一：使用运行对话框**
1. 按 `Win+R` 打开运行对话框
2. 输入：`%APPDATA%/r2-storage-manager/logs`
3. 按 `Enter` 打开文件夹
4. 使用文本编辑器打开 `error.log`

**方法二：使用命令行**
```cmd
notepad %APPDATA%/r2-storage-manager/logs/error.log
```

### 日志内容

日志包含以下信息：
- 错误发生时间
- 错误类型
- 错误详情
- 堆栈跟踪（用于调试）

### 使用日志排查问题

1. 复现问题
2. 查看日志文件
3. 找到对应时间点的错误记录
4. 根据错误信息进行排查

## 环境变量配置

### 方法一：使用 .env 文件

1. 在应用程序目录创建 `.env` 文件
2. 添加以下内容：
   ```ini
   R2_ACCESS_KEY_ID=your_access_key_id
   R2_SECRET_ACCESS_KEY=your_secret_access_key
   ```
3. 保存文件
4. 重启应用程序

### 方法二：设置系统环境变量

1. 右键"此电脑" → "属性"
2. 点击"高级系统设置"
3. 点击"环境变量"
4. 在"用户变量"中点击"新建"
5. 添加变量：
   - 变量名：`R2_ACCESS_KEY_ID`
   - 变量值：您的 Access Key ID
6. 重复步骤 4-5 添加 `R2_SECRET_ACCESS_KEY`
7. 点击"确定"保存
8. **重启应用程序**

### 验证环境变量

打开命令提示符，执行：
```cmd
echo %R2_ACCESS_KEY_ID%
echo %R2_SECRET_ACCESS_KEY%
```

如果输出您的凭证值，说明配置成功。

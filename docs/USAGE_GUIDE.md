## 界面概览

### 主窗口

R2 存储管理器的主窗口由以下几个部分组成：

```
┌─────────────────────────────────────────────────────────────────┐
│  标题栏 - 显示应用程序名称 "R2 存储管理器"                        │
├─────────────────────────────────────────────────────────────────┤
│  工具栏 - 包含常用操作按钮                                        │
│  [上传] [下载] [预览] [删除] [刷新]                               │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  对象列表 - 显示存储桶中的所有文件                                │
│  ┌────┬──────────────────┬──────────┬────────────────────┐      │
│  │图标│      文件名       │   大小   │     修改时间       │      │
│  ├────┼──────────────────┼──────────┼────────────────────┤      │
│  │    │                  │          │                    │      │
│  └────┴──────────────────┴──────────┴────────────────────┘      │
│                                                                 │
├─────────────────────────────────────────────────────────────────┤
│  状态栏 - 显示当前状态和对象数量                                  │
│  就绪                                          共 X 个对象       │
└─────────────────────────────────────────────────────────────────┘
```

### 工具栏按钮

| 按钮 | 功能 | 快捷键 |
|------|------|--------|
| 📤 上传 | 上传文件到存储桶 | `Ctrl+U` |
| 📥 下载 | 下载选中的文件 | `Ctrl+D` |
| 👁️ 预览 | 预览选中的文件 | `Enter` |
| 🗑️ 删除 | 删除选中的文件 | `Delete` |
| 🔄 刷新 | 刷新对象列表 | `Ctrl+R` |

### 对象列表

对象列表以表格形式显示存储桶中的所有文件：

- **图标列**：根据文件类型显示不同的图标
- **文件名列**：显示文件的完整名称
- **大小列**：显示文件大小（自动转换单位）
- **修改时间列**：显示文件的最后修改时间

### 状态栏

状态栏显示以下信息：

- **左侧**：当前操作状态
  - "就绪" - 空闲状态
  - "正在加载..." - 正在加载列表
  - "正在上传..." - 正在上传文件
  - "正在下载..." - 正在下载文件
- **右侧**：对象总数

## 基本操作

### 上传文件

**步骤**：

1. 点击工具栏的 **"上传"** 按钮（或按 `Ctrl+U`）

   ![上传步骤1](screenshots/upload-step1.png)
   *图：点击上传按钮*

2. 在弹出的文件选择对话框中，选择要上传的文件

   ![上传步骤2](screenshots/upload-step2.png)
   *图：选择要上传的文件*

3. 点击"打开"按钮开始上传

4. 状态栏显示上传进度

   ![上传进度](screenshots/upload-progress.png)
   *图：上传进度显示*

5. 上传完成后，显示成功提示，列表自动刷新

   ![上传成功](screenshots/upload-success.png)
   *图：上传成功提示*

**注意事项**：
- 上传会保留原始文件名
- 如果存在同名文件，将被覆盖
- 大文件上传可能需要较长时间

### 下载文件

**步骤**：

1. 在对象列表中选择要下载的文件

   ![选择文件](screenshots/select-file.png)
   *图：选择要下载的文件*

2. 点击工具栏的 **"下载"** 按钮（或按 `Ctrl+D`）

3. 在弹出的保存对话框中，选择保存位置和文件名

   ![保存对话框](screenshots/save-dialog.png)
   *图：选择保存位置*

4. 点击"保存"按钮开始下载

5. 状态栏显示下载进度

6. 下载完成后，显示成功提示

**注意事项**：
- 默认使用原始文件名
- 如果目标文件已存在，会提示是否覆盖
- 确保有足够的磁盘空间

### 预览文件

**步骤**：

1. 在对象列表中选择要预览的文件

2. 点击工具栏的 **"预览"** 按钮（或按 `Enter`）

3. 预览窗口打开，显示文件内容

   ![预览窗口-图片](screenshots/preview-image.png)
   *图：图片预览窗口*

   ![预览窗口-文本](screenshots/preview-text.png)
   *图：文本预览窗口*

**支持的预览类型**：

| 文件类型 | 支持的格式 | 预览方式 |
|----------|-----------|----------|
| 图片 | jpg, jpeg, png, gif, webp, svg, bmp, ico | 图片查看器 |
| 文本 | txt, md, json, xml, html, css, js, ts, yaml, yml, log | 文本查看器 |
| 其他 | 其他所有格式 | 显示文件信息 |

**注意事项**：
- 大文件预览可能较慢
- 文本文件使用 UTF-8 编码显示
- 不支持的格式会显示文件信息

### 删除文件

**步骤**：

1. 在对象列表中选择要删除的文件

2. 点击工具栏的 **"删除"** 按钮（或按 `Delete`）

3. 在确认对话框中查看提示信息

   ![删除确认](screenshots/delete-confirm.png)
   *图：删除确认对话框*

4. 点击"确定"确认删除，或点击"取消"放弃

5. 删除完成后，显示成功提示，列表自动刷新

**注意事项**：
- ⚠️ 删除操作无法撤销
- 请确认文件不再需要后再删除
- 删除后文件将永久丢失

### 刷新列表

**步骤**：

- 点击工具栏的 **"刷新"** 按钮（或按 `Ctrl+R`）

**说明**：
- 刷新会重新从 R2 存储桶获取最新的对象列表
- 适用于其他地方上传/删除文件后同步列表

## 高级功能

### 复制 URL

R2 存储管理器支持将文件 URL 复制为多种格式，方便在不同场景使用。

**操作方式**：

1. 右键点击要复制 URL 的文件

   ![右键菜单](screenshots/context-menu.png)
   *图：右键菜单*

2. 选择复制格式：

   | 菜单项 | 格式 | 使用场景 |
   |--------|------|----------|
   | 复制链接 | `https://example.com/file.png` | 直接使用 URL |
   | 复制 HTML | `<img src="https://..." alt="file" />` | 网页开发 |
   | 复制 Markdown | `![file](https://...)` | Markdown 文档 |

3. 复制成功后显示提示

**使用示例**：

**复制链接**：
```
https://pub-xxx.r2.dev/image.png
```

**复制 HTML**：
```html
<img src="https://pub-xxx.r2.dev/image.png" alt="image" />
```

**复制 Markdown**：
```markdown
![image](https://pub-xxx.r2.dev/image.png)
```

### 右键菜单

右键点击对象列表中的文件，可以快速访问以下功能：

```
┌─────────────────────┐
│ 上传                │
│ 下载                │
│ 预览                │
│ 删除                │
├─────────────────────┤
│ 复制链接            │
│ 复制 HTML           │
│ 复制 Markdown       │
└─────────────────────┘
```

### 键盘快捷键

使用键盘快捷键可以提高操作效率：

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+U` | 上传文件 |
| `Ctrl+D` | 下载选中文件 |
| `Ctrl+R` | 刷新列表 |
| `Delete` | 删除选中文件 |
| `Enter` | 预览选中文件 |

| `Ctrl+Shift+C` | 显示复制格式菜单 |
| `↑` / `↓` | 选择上/下一个文件 |

## 最佳实践

### 文件命名建议

- 使用有意义的文件名，便于识别
- 避免使用特殊字符（如 `?`, `&`, `#`, 空格等）
- 使用小写字母和连字符（如 `my-image.png`）
- 对于图片，建议包含尺寸或用途信息

### 文件组织建议

- 按类型分类存储（如 `images/`, `documents/`, `videos/`）
- 使用日期前缀（如 `2024-01-15-report.pdf`）
- 定期清理不需要的文件

### 安全建议

- 定期更换 API Token
- 为不同用途创建不同的 Token
- 不要分享您的凭证
- 定期检查存储桶访问日志

### 性能优化建议

- 大文件建议在网络良好时上传/下载
- 定期刷新列表以获取最新状态
- 关闭不需要的预览窗口

## 常见问题

### 如何查看文件的完整 URL？

1. 选择文件
2. 右键点击
3. 选择"复制链接"
4. 粘贴到任意文本编辑器查看

### 如何批量操作？

当前版本不支持批量操作。如需批量上传/下载/删除，请逐个操作或等待后续版本更新。

### 如何切换存储桶？

当前版本使用固定存储桶配置。如需访问其他存储桶，需要修改配置文件。

### 预览显示乱码怎么办？

文本文件预览使用 UTF-8 编码。如果显示乱码，可能是文件使用了其他编码。建议下载后使用文本编辑器打开并选择正确的编码。

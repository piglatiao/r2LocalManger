## 快速开始

### 第一步：获取 Cloudflare R2 凭证

1. 登录 [Cloudflare Dashboard](https://dash.cloudflare.com/)
2. 进入 **R2 对象存储** 服务
3. 创建或选择您的存储桶
4. 点击 **管理 R2 API 令牌**
5. 创建新的 API 令牌，记录以下信息：
   - **Access Key ID**（访问密钥 ID）
   - **Secret Access Key**（秘密访问密钥）

> ⚠️ **重要提示**：请妥善保管您的凭证，不要分享给他人。

### 第二步：在应用内配置

1. 启动应用程序，打开工具栏中的 **设置**。
2. 在 **凭证配置** 中填写 Access Key ID 和 Secret Access Key。
3. 在存储桶设置中确认 Endpoint、账户信息和当前存储桶。
4. 点击 **测试连接**，确认成功后保存设置。

配置保存在应用本地存储中，敏感凭证优先使用 Electron `safeStorage` 加密保存。应用运行时不会从项目文件或系统环境变量读取 R2 配置。

> 启动说明：
> 应用启动后会先检查当前是否已有可用配置。
> 未检测到凭证或必要配置时，只会提示前往“设置”完成配置，不会继续做连接检查。
> 如果本地已保存配置，可直接使用；只有检测到配置完整但连接失败时，才会提示检查连接或配置。

### 第三步：安装和运行

#### 开发模式

```bash
# 安装依赖
npm install

# 启动开发模式
npm run dev
```

#### 生产安装

1. 下载安装程序（`dist/` 目录下的 `.exe` 文件）
2. 双击运行安装程序
3. 按照安装向导完成安装
4. 启动应用程序

### 基本操作

#### 上传文件

1. 点击工具栏的 **"上传"** 按钮，或按 `Ctrl+U`
2. 在弹出的文件选择对话框中选择要上传的文件
3. 点击"打开"开始上传
4. 状态栏显示上传进度
5. 上传完成后显示成功提示，列表自动刷新

#### 下载文件

1. 在对象列表中选择要下载的文件
2. 点击工具栏的 **"下载"** 按钮，或按 `Ctrl+D`
3. 在弹出的保存对话框中选择保存位置
4. 点击"保存"开始下载
5. 状态栏显示下载进度
6. 下载完成后显示成功提示

#### 预览文件

1. 在对象列表中选择要预览的文件
2. 点击工具栏的 **"预览"** 按钮，或按 `Enter`
3. 预览窗口打开并显示文件内容

**支持的预览类型：**

| 类型 | 支持的格式 |
|------|-----------|
| 图片 | jpg, jpeg, png, gif, webp, svg, bmp, ico |
| 文本 | txt, md, json, xml, html, css, js, ts, yaml, yml, log |
| 其他 | 显示文件信息（名称、大小、类型） |

#### 删除文件

1. 在对象列表中选择要删除的文件
2. 点击工具栏的 **"删除"** 按钮，或按 `Delete`
3. 在确认对话框中点击"确定"
4. 删除完成后显示成功提示，列表自动刷新

> ⚠️ **注意**：删除操作无法撤销，请谨慎操作。

#### 刷新列表

- 点击工具栏的 **"刷新"** 按钮，或按 `Ctrl+R`
- 列表将重新加载最新的对象信息

### 复制 URL 功能

右键点击对象，可以复制不同格式的 URL：

| 菜单项 | 格式 | 示例 |
|--------|------|------|
| 复制链接 | 纯 URL | `https://example.com/image.png` |
| 复制 HTML | HTML img 标签 | `<img src="https://example.com/image.png" alt="image" />` |
| 复制 Markdown | Markdown 图片 | `![image](https://example.com/image.png)` |

## 故障排除

遇到问题时，先打开设置页测试连接，并查看应用日志定位具体错误。

### 常见问题

#### ❌ 应用启动时显示"配置错误"

**原因**：设置页未保存完整凭证或连接参数

**解决方法**：
1. 打开 **设置**，确认 Access Key ID 和 Secret Access Key 不为空
2. 确认 Endpoint、账户信息和存储桶配置正确
3. 点击 **测试连接**，成功后保存设置

#### ❌ 认证失败

**原因**：凭证无效或权限不足

**解决方法**：
1. 检查 Access Key ID 和 Secret Access Key 是否正确
2. 确认 API Token 具有访问目标存储桶的权限
3. 在 Cloudflare Dashboard 中验证凭证是否仍然有效
4. 尝试重新生成 API Token

#### ❌ 网络连接失败

**原因**：无法连接到 Cloudflare R2 服务

**解决方法**：
1. 检查网络连接是否正常
2. 确认防火墙未阻止应用程序访问网络
3. 尝试访问 Cloudflare Dashboard 确认服务状态
4. 检查是否需要配置代理

#### ❌ 存储桶不存在或无法访问

**原因**：存储桶名称错误或权限不足

**解决方法**：
1. 确认存储桶名称是否正确
2. 检查 API Token 是否有访问该存储桶的权限
3. 在 Cloudflare Dashboard 中确认存储桶是否存在

#### ❌ 文件上传/下载失败

**原因**：网络问题、权限问题或磁盘空间不足

**解决方法**：
1. 检查网络连接状态
2. 确认有足够的磁盘空间（下载时）
3. 检查文件是否被其他程序占用
4. 查看错误日志获取详细信息

### 查看日志

应用程序日志位于：
```
%APPDATA%/r2-storage-manager/logs/error.log
```

查看方法：
1. 按 `Win+R` 打开运行对话框
2. 输入 `%APPDATA%/r2-storage-manager/logs`
3. 打开 `error.log` 文件

## 安全注意事项

⚠️ **重要安全提示**：

- 🔐 凭证只在应用设置中维护，并通过本地安全存储保护
- 🔐 `.gitignore` 保留旧版本地配置文件的忽略规则，避免历史文件误提交
- 🔐 不要把应用本地存储目录复制给他人
- 🔐 不要在代码中硬编码凭证信息
- 🔐 定期更换 API Token 以提高安全性
- 🔐 为 API Token 设置最小必要权限
- 🔐 不要与他人分享您的凭证
